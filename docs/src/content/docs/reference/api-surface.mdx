## Package entry point

The package is imported as:

```python
import cooprecsys
```

Model functionality is organized beneath the `models` package. The project README demonstrates direct imports for the documented model families, for example:

```python
from src.models.arycolbring import AryColBring
```

and LTR workflows through the LTR modules.

## Integration recommendation

For application integration, keep the following boundaries explicit:

- **data layer** — input normalization and loading,
- **feature layer** — deterministic feature transformations,
- **model layer** — training/inference,
- **evaluation layer** — offline metrics,
- **explainability layer** — diagnostics and narrative reports,
- **application layer** — business-specific orchestration.

This separation makes it easier to test inference independently from the training pipeline and to version feature transformations alongside the model artifact.
