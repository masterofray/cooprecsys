## Design boundary

The structure separates concerns rather than forcing every capability into the model classes. This is useful for maintenance because data preparation, model training, report generation, and dashboard support can evolve independently.

## Native extension directories

`CLproximity/` and `CLtowers/` are special cases. They contain Cython sources and generated native binaries. When distributing through PyPI, prefer built wheels so end users receive a tested artifact rather than compiling those modules ad hoc.
