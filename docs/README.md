# CoopRecSys Documentation

Astro documentation site for the CoopRecSys Python recommendation-system package.

## Local development

```bash
cd docs
npm install
npm run dev
```

## Build

```bash
cd docs
npm run build
```

## GitHub Pages

The site is deployed by `.github/workflows/deploy-docs.yml` to:

https://masterofray.github.io/cooprecsys
